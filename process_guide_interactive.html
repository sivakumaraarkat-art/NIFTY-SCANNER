Technical Indicator Calculator
historical_market_data/technical_indicator_calculator.py

Calculates exact moving averages, Wilder's smoothed RSI, and volatility spread indicators.

📊 Wilder's Smoothed RSI (14) Formulation

Unlike standard simple RSI, Wilder's RSI applies exponential smoothing over gains and losses to prevent false whipsaws in Indian equity swings:

delta = df['close'].diff()
gain = delta.where(delta > 0, 0.0)
loss = -delta.where(delta < 0, 0.0)

avg_gain = gain.ewm(alpha=1/14, min_periods=14, adjust=False).mean()
avg_loss = loss.ewm(alpha=1/14, min_periods=14, adjust=False).mean()

rs = avg_gain / avg_loss
df['rsi'] = 100 - (100 / (1 + rs))
Ranking & Position Sizing Engine
trade_selection/position_size_calculator.py & swing_candidate_ranker.py

Computes risk-controlled quantities and dynamic profit targets based on volatility.

Position Sizing Formula

🛡️ The 1% Account Risk Calculation

Quantity = int( (Total Capital × Risk Fraction) / |Entry Price - Stop Loss| )

Example Calculation:

  • Total Trading Capital = ₹5,00,000
  • Risk per Trade = 1% (₹5,000 max loss)
  • Stock: RELIANCE | Entry = ₹2,500 | Stop Loss = ₹2,400
  • Risk per share = ₹100
  • Quantity to Buy = ₹5,000 / ₹100 = 50 Shares

Historical Data & Caching Pipeline
zerodha_market_data/market_data_downloader.py

Prevents destructive API rate-limiting via resilient file-based caching and exponential backoff retry algorithms.

Data Fetch Logic

  • Parquet / CSV Hybrid Cache: Searches for local NSE_SYMBOL_daily.parquet or .csv. If its modification stamp is under 24 hours, it skips network I/O.
  • Self-Healing Re-Attemps: Downloads missing records with up to 3 retries spacing via delay = base * (2^attempt) handling.
  • Atomic Write: Saves data via a temporary file (.tmp.parquet) prior to renaming it to guard against partial memory dumps during power outages.
