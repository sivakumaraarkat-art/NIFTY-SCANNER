🛡️ Improvement #1: Weekend & Holiday Guard

What It Does

Prevents scanner execution on weekends and NSE public holidays. The script checks the current date at startup and terminates gracefully if it's not a trading day.

Coverage

  • Weekends: Saturday & Sunday (automatically detected)
  • NSE Holidays: 15 holidays defined for 2026
  • Expandable: Easy to add holidays for future years

Implementation

def is_trading_day() -> bool: """Check if today is a valid NSE trading day.""" today = datetime.now() # Weekend check if today.weekday() >= 5: # Saturday=5, Sunday=6 return False # Holiday check today_date = today.replace(hour=0, minute=0, second=0, microsecond=0) if today_date in NSE_HOLIDAYS_2026: return False return True # In main(): if not is_trading_day(): print("⚠️ HALT: Today is NOT a trading day") print(" Scanner only runs on trading days.") return

🗑️ Improvement #2: Log Rotation

What It Does

Automatically deletes log files older than 30 days at scanner startup. This prevents the logs/ directory from accumulating gigabytes of old JSON files over time.

How It Works

def cleanup_old_logs(log_dir: Path = Path("logs"), days_to_keep: int = 30) -> None: """Delete log files older than specified days.""" if not log_dir.exists(): return now = datetime.now() cutoff = now - timedelta(days=days_to_keep) deleted_count = 0 try: for log_file in log_dir.glob("*.json"): try: file_mtime = datetime.fromtimestamp(log_file.stat().st_mtime) if file_mtime < cutoff: log_file.unlink() deleted_count += 1 except Exception: pass # Skip files we can't delete if deleted_count > 0: print(f"🗑️ Cleaned up {deleted_count} log files") except Exception: pass # Don't fail if cleanup has issues

Impact Analysis

Metric Without Rotation With Rotation Savings
Daily Scans 3 runs × 365 = 1,095 files 3 runs × 30 = ~90 files 92% reduction
Avg File Size ~20KB each ~20KB each N/A
Total Space/Year ~22 MB ~2 MB (rolling) 20 MB saved
Cleanup Overhead Manual or never Automatic <10ms Hands-free

Features

  • Configurable retention: Default 30 days (easy to change)
  • Safe deletion: Gracefully handles permission errors
  • Silent operation: Only reports when files are deleted
  • No dependencies: Uses only Python stdlib

Console Output

When log files are deleted, you'll see:

Why It Matters

  • Disk Management: Prevents accumulation of old files

  • Hands-Free: No manual cleanup required
